# Calorie Counter SPA

A modern, fast Single Page Application to calculate your energy expenditure seamlessly.
Re-written from an old python terminal script into a smart React interface.

## Features
- Searchable activity list
- Real-time calorie expenditure calculation based on weight and duration
- Seamless switching between Lbs and Kg
- Add activities to a daily log to see total calories burned

## Getting Started

Make sure you have [Node.js](https://nodejs.org/) installed.

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Tech Stack
- React + TypeScript
- Vite
- Tailwind CSS
- Lucide Icons
